# Performance Baseline Evidence

Validated synthetic WebRTC loopback observations are stored here.

## Evidence levels

- `HarnessValidation` — harness self-check only
- `BrowserSyntheticMediaPath` — AudioContext pulse through RTCPeerConnection loopback
- `BrowserNetworkObservation` — live two-peer session network metrics

## Privacy

Evidence artifacts must NOT contain IP addresses, SDP, ICE candidates, device IDs, or media device labels.

## Status

All artifacts carry `evidence_status: exploratory_non_authoritative`.

## Disclaimer

Exploratory non-authoritative performance observation. Not an acoustic mouth-to-ear measurement. Not a transport selection result.
