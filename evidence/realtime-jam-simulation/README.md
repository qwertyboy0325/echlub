# Real-Time Jam Simulation Outputs

Generated by `python3 scripts/run-jam-simulation.py --label <label>`.

> **SIMULATION, NOT EVIDENCE.** Network, device, and musician parameters are
> assumed planning values (`Provenance::Assumed`). These outputs guide design
> and must not be cited as latency measurements of real networks, devices, or
> people.

## Layout

- `<label>/matrix.md`: every Taiwan preset × endpoint × topology.
- `<label>/scenarios/<preset>--<endpoint>--<topology>/scenario.{json,md}`:
  pipeline simulation (probe-measured network path + analytic device budget)
  and simulated-ensemble results.
- `<label>/sweep-*/sweep.{json,md}`: rock four-piece latency tolerance.
- `<label>/mobile-study-<role>/mobile-study.{json,md}`: one player on 4G/5G
  (direct, phone hotspot over Wi-Fi or USB, 5G SA) with remedies: jitter
  buffer coverage, packet redundancy, follower and click-ahead arrangements.
- `<label>/iphone-target/`: ADR-0007 target (all iPhone, wired monitoring)
  across networks, buffer sizes, and a Bluetooth contrast.
- `<label>/phone-terminals/`: phones as terminals (one phone in a wired
  band, and all-phone bands) across phone audio paths and access types.
- `<label>/udp-bots-probe-*/bots.{json,md}`: real UDP sockets on one host with
  injected impairment; describes that host only.

Audio renderings (`--wav`) are not committed; regenerate them locally.
